# Сперва поискать готовое в py_modules

Функций в общем слое под пять сотен, реестра и точки входа у него нет. **Второй вариант
уже существующей функции пишется обычно не от лени, а оттого, что первую не нашли.**

Вход один: сказать словами, что нужно сделать.

## 1. Спросить

```bash
PYTHONPATH=py_modules python -m tool_.tool_find "снять экран телефона"   # из проекта
PYTHONPATH=.          python -m tool_.tool_find "снять экран телефона"   # из самого py_modules
```

Полторы секунды. Опись собирается обходом дерева на лету — индекса на диске нет,
устаревать нечему: переименованная вчера функция видна сегодня же.

Слоя нет на месте (`ModuleNotFoundError: No module named 'tool_'`) — значит в проекте он
подключён submodule-ом и не выкачан: `git submodule update --init --recursive`.

## 2. Спрашивать коротко

Поиск **лексический**, морфологию ловит, смысл — нет. Отсюда правила вопроса:

- одно короткое намерение, а не предложение;
- слово из описи: `«коммит-сообщение»`, а не `«проверить коммит-сообщение»`;
- два шумных слова уже размазывают ранжирование — лучше два отдельных вопроса, чем один
  длинный.

Слова не дали ничего — `--map` покажет карту namespace-ов и тем, дальше искать по ней:

```bash
PYTHONPATH=py_modules python -m tool_.tool_find --map
```

## 3. Прочитать ответ

Выдача двух видов, и они отвечают на разные вопросы:

| | что это | зачем |
|---|---|---|
| 🔧 | публичная функция, путь и первая строка докстринга | **чем это делают** |
| 📄 | тема из `docs/` | **как устроено и обо что уже спотыкались** |

Идут обычно за вторым, а зовут первое, поэтому в описи лежат обе половины. Метка `[CLI]`
значит, что у модуля есть точка входа: `python -m <модуль> --help`.

Нашлось — открыть файл и прочитать докстринг целиком (блок `⚠` там про грабли), а тему
из `docs/` — прочитать прежде, чем звать. Импорт короткий, без префикса `py_modules.`:
`from config.config import config_get`.

## 4. Когда действительно ничего нет

Только тогда писать своё — по `docs/code_rules.md`: префикс функции = namespace файла,
приватные внизу, докстринг обязателен. Новый инструмент общего толка кладут в слой, а не
в проект, — правила правок слоя в `py_modules/CLAUDE.md`.

⚠ Функция нашлась поиском, но в проекте её нет (в `py_modules/` проекта её файла нет) —
это отставший указатель submodule, а не отсутствие функции. Лечится сдвигом указателя,
а не переписыванием: в проекте `git -C py_modules fetch && git -C py_modules merge
--ff-only origin/master`, затем `git commit -- py_modules` отдельным коммитом.
