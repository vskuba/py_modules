# Режим DSH: high / free / off

Аргумент — `high`, `free` или `off`; пусто — показать текущий режим.

1. Выполни одну команду (сессия берётся из `CLAUDE_CODE_SESSION_ID`):

   ```bash
   cd /tmp && dsh-board mode <аргумент>      # без аргумента — показать
   ```

   Хук `claude_hook_dsh_mode` обычно уже записал режим по самому сообщению `/dsh <режим>` —
   повторная запись безвредна.
2. Ответь человеку одной строкой: какой режим теперь у сессии. Больше ничего не делай.

Что значит каждый режим и где он хранится — `docs/dsh_board.md` §7 общего слоя.
Правило режима приходит в контекст каждого хода само (хук `UserPromptSubmit`).
