# User agent — профили браузеров, а не список строк

> Подставить случайный `User-Agent` мало. Сайт смотрит не на строку, а на
> **набор**: заявился Chrome на Windows, а `Sec-CH-UA-Platform` говорит
> «Linux», `Accept-Language` пуст, `Sec-Fetch-*` нет вовсе — это не человек.
> Такой гость заметнее, чем вовсе без подмены.

## 1. Как звать

```python
from useragent_.useragent_ import useragent_pick, useragent_headers

profile = useragent_pick(['chrome-win', 'safari-iphone'])   # по долям
headers = useragent_headers(profile, referer='https://shop.local/')
```

| Функция | Контракт |
|---------|----------|
| `useragent_list()` | все профили справочника (копии) |
| `useragent_find(code)` | профиль по коду; нет — пустой словарь |
| `useragent_pick(codes, rand)` | профиль по долям; `codes` сужает выбор |
| `useragent_headers(profile, referer)` | заголовки, согласованные с профилем |

## 2. ⚠⚠ Клиентские подсказки — только тем, кто их шлёт

`Sec-CH-UA` есть у семейства Chromium и **нет** у Safari и Firefox. Приписать
их Safari значит выдать себя тем самым, чем прикрывались.

Версия в `Sec-CH-UA` обязана совпадать с версией в строке: Chrome шлёт обе, и
сайт, сверяющий их, видит подделку мгновенно.

## 3. ⚠⚠ `Accept-Encoding` не подставляется

Его ставит сам клиент — тем, что умеет разжать. Объяви `br`, а библиотека без
brotli — и сервер пришлёт сжатое тело, которое не развернётся: страница приедет
двоичным мусором. Поймано на живом поиске: после подстановки заголовков разбор,
находивший пятнадцать товаров, стал находить ноль.

## 4. ⚠ Доли, а не поровну

Chrome на Windows — две трети живого трафика, Firefox на Linux — редкость.
Ровный выбор даёт набор, где каждый десятый гость сидит на редкости, и это
видно в любой аналитике.

## 5. ⚠ Версии стареют

Chrome выходит раз в месяц; профиль двухлетней давности выглядит как человек,
не обновлявший браузер два года. Дата последней правки — `USERAGENT_UPDATED_AT`.

## 6. Чего здесь нет

Подмены отпечатка холста, шрифтов и WebGL. Строка `User-Agent` говорит, кем
гость назвался, отпечаток — кем он оказался. Модуль отвечает за первое.

⚠ Браузеру профиль передают через `browser_pool_session_open(user_agent=…,
extra_headers=…)` или `browser_scenario_execute(...)`. Заголовки ставятся на
**контекст**, а не на запрос: их должны нести и переходы, и подзапросы
страницы, иначе первый же XHR уедет с умолчанием образа.
