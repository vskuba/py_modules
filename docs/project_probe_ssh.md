# Project probe ssh — домен-код внутри контейнера прода

> `project_/project_probe_ssh.py`: кусок кода исполняется поднятым контейнером
> на том хосте — его `PYTHONPATH`, его `.env`, имена сервисов из внутренней
> сети. Ответ — stdout; чужой код возврата — `RuntimeError` с хвостом stderr.

    PYTHONPATH=py_modules python3 project_/project_probe_ssh.py \
        -a "from src.dating.site_setting import SITE_KNOWN as S; print(len(S))" \
        --target rhapsody-prod --container uvicorn

## 1. Зачем

Проверить, что код на проде **есть и устроен как задумано**, глазами по диффу
нельзя: выкладка идёт архивом, репозитория на машине нет, а вопрос «реестр
настройки вообще собрался с новым ключом?» — это вопрос не к файлам, а к
**живому импорту**. Ровно так в бою и рождались строки

```bash
ssh хост 'cd ~/app && docker exec контейнер python -c "from x import y; print(...)"'
```

с двойным поеданием кавычек (shell → sh контейнера) и невозможностью
многострочного кода. `project_probe` — двойник приёма, но исполняет код **на
хосте разработчика** с подменой адресов; к чужой машине у него дороги нет.

## 2. Устройство

Три способа исполнить домен-код, и путать их дорого:

| Чем | Где исполняется | Когда |
|-----|-----------------|-------|
| `project_probe` | хост разработки, адреса наружу | логика, БД, конфиг локального стека |
| `docker_compose_python` | контейнер **локального** compose | то же, но окружением поднятого сервиса |
| `project_probe_ssh` | контейнер **на том хосте** | реестры, импорты, состав функций живого стека |

Код доезжает через stdin (`printf %s "$DSH_CODE" > tmp`), а не аргументом:
кавычки любого сорта доходят целыми. Контейнер ищется в два шага — точное имя
через `docker inspect`, иначе подстрока среди поднятых (`uvicorn` найдёт
`dating_uvicorn`). Интерпретатор выбирается внутри контейнера: `python`, нет —
`python3`, образами на slim-без-`python` это не ломается.

Тело с `await` оборачивается в корутину тем же правилом, что у `project_probe`.

## Грабли

⚠ **Нумерация строк в трейсбеке съезжает на 4** — размер шапки обёртки
`asyncio`. Сдвиг постоянный: строка куска + 4.

⚠ **Смотреть надо на код возврата контейнера, не ssh**: скрипт завершается
кодом процесса, поэтому `Traceback` внутри — это `RuntimeError` здесь, а не
молчаливый пустой stdout.

⚠ **Имя контейнера — подстрока**, берётся **первое** совпадение: на стенде с
двумя панелями `uvicorn` попадёт в поднятый раньше. Точное имя всегда
выигрывает (`docker inspect` спрашивается первым).

⚠ **Это не проверка работы, это проверка кода.** Ручки и круги отсюда не
зовут — база и очередь живые; только импорт, реестр, сигнатура.
