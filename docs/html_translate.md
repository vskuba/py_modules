# html_translate — перевод HTML-отчёта локальной моделью, секция за секцией

> Translate html report to russian / html translation with local llm: в отчёте
> живут `<code>`, JSON, URL, uuid и продуктовые имена — обычный машинный
> перевод ломает их вместе с разметкой; здесь переводит локальный GX10 по
> кускам, а после каждого куска мультимножество тегов и число `<img>` сверяются
> с оригиналом.

## 1. Порядок работы

`html_translate(src, out, lang='ru')` — файл лёг, файл переведён (по умолчанию
рядом `<имя>.<lang>.html`). Внутри — `html_translate_html`: голова со стилями
и всё за `</body>` не участвуют вовсе, `<body>` режется `re.split` перед каждым
`<h2>` (секция = кусок = запрос), каждый кусок уходит модели
(`html_translate_gx10`: материал через stdin, инструкция аргументом,
`-s system -t 6000 --timeout 600`) и после ответа сверяется по разметке.
Атрибут `lang` у `<html>` ставится целевому языку. Переводчик подменяется
аргументом `call(text, system)` — тесты живут без бинаря.

## 2. Охрана текста

Системный промпт запрещает трогать теги, атрибуты, `<code>`, JSON, URL, uuid,
числа, коды валют, имена полей, хеши коммитов и слова PASS / FAIL; наружу —
только HTML куска, ограждение кода снимается. Словарь `--glossary terms.txt`
(JSON-объект или построчно `термин = перевод`) задаёт фиксированные
соответствия, `--keep HeroPayments` — слова, которым переводить нельзя.

## 3. Сверка после каждого куска

Не сошлось мультимножество тегов (открывающие и закрывающие считаются раздельно)
или число `<img>` — кусок запрашивается ещё раз; не сошлось и тогда —
RuntimeError со списком различий. Молча перевранный отчёт хуже упавшего:
потерянный `</ul>` в середине отчёта глазами не находится.

## 4. Грабли

- ⚠ Резать по `(?=<h2[\s>])`, не по `<h2>`: заголовок с классом
  (`<h2 class=…>`) иначе уезжает целиком в прошлый кусок, и граница секции
  теряется.
- ⚠ Правка молча ломает кириллицу буквами из латиницы — перед коммитом
  `python -m tool_.tool_typo`; промпт-то англо-русский, смешение алфавитов тут
  дешевле, чем кажется.
- ⚠ GX10 медленный: кусок может думать минуты, `--timeout 600` на то и
  поставлен; бинарь ищется в `~/.claude/bin/gx10`, наружу — `GX10_BIN`.
- ⚠ `src` — подсказка, не проверка: модель видит текст куска, но не знает,
  откуда он переводился; языки вперемешку в исходнике она переведёт как есть —
  это править исходник, а не промпт.
