# Сокеты машины: кто держит и куда тянется

> Разбор «что-то висит на соединении» или «кто-то долбит один адрес» руками —
> это `ss -tn`, угадывание pid'ов и обход `/proc/*/fd` или `docker`. `net_port`
> отвечает на «порт жив ли» и сознательно без владельцев; здесь другой вопрос —
> **чей** сокет. Одна команда даёт таблицу соединений хоста и каждого контейнера.

## 1. Снимок

```python
from net_.net_sockets import net_sockets_list

net_sockets_list()                       # живые TCP: ESTAB, SYN, FIN-WAIT, CLOSE-WAIT…
net_sockets_list(all_states=True)        # плюс LISTEN и TIME-WAIT
net_sockets_list(grep='3306')            # фильтр подстрокой по любому полю
net_sockets_list(containers=False)       # только хост, без `docker exec`
```

Каждая строка — `{'container', 'state', 'local', 'peer', 'pid', 'command'}`:
`container` пуст у хостовых, `pid`/`command` пусты, когда процесса не видно
(чужой владелец, внутренний сокет контейнера).

## 2. Почему обход, а не один `ss`

Хост видит **только своё** сетевое пространство: сокет контейнера с собственным
netns наружу не виден вовсе. Поэтому инструмент ходит в два места — хостовый
`ss -tanp` и `/proc/net/tcp*` каждого поднятого контейнера (`ss` в рабочих
образах не водится, а proc есть всегда). Хостовый pid сворачивается в имя
контейнера: цепочка родителей в `/proc` поднимается до init-процесса из
`docker inspect`.

```bash
PYTHONPATH=. python -m net_.net_sockets                    # сводка по состояниям
PYTHONPATH=. python -m net_.net_sockets --grep CLOSE-WAIT  # зависшие полузакрытия
PYTHONPATH=. python -m net_.net_sockets --all --format json
```

## Грабли

- **хостовый `ss` слеп к чужому netns**: «в хосте соединения нет» не значит
  «его нет нигде» — база и панель живут в контейнерах, их видно только обходом.
- **pid без прав пуст**: `ss` показывает процессы своего владельца; имя
  контейнера при этом всё равно находится — по docker и цепочке родителей.
- **снимок, а не трекер**: хост и контейнеры опрашиваются подряд, состояние
  между опросами меняется; для наблюдения за одним адресом зовите заново.
- **TIME-WAIT — не соединение**: по умолчанию их нет, `--all` показывает и их,
  и LISTEN; иначе лента на сотню строк из мусора, который никто не ждал.
