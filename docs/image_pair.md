# Image Pair — сверка пары кадров построчно и вшивка полосы

> Два кадра одного размера: `image_pair_diff_rows` показывает, **какие строки
> и где именно** отличаются (сетка 3×3 из `image_diff_zones` для этого
> крупна), `image_pair_splice` вшивает в артефакт полосу из второго кадра —
> когда верх правлен руками и перегенерация запрещена, а низ чинят.

## 1. Сверка: где лежат ручные правки

Прежде чем перезаписать артефакт перегенерацией, так ищут, что в нём правили
руками — островки различий показывают строки, а не «зона изменилась»:

```bash
python -m image_.image_pair diff-rows deployed.webp fresh.webp --thresh 8
# -> пикселей N, макс M, групп K; «строки 1564..1623», «островки: (x0,y0,x1,y1)»
```

`thresh` — порог по каналу; идущие подряд отличающиеся строки слипаются в
интервал, `bbox` обнимает все островки разом. Тот же `--axis x` считает по
столбцам. Порог ниже шумов кодирования (webp q90 — единицы), правки и фиксы
видны с порогом 6–8; дельты меньше порога — «тишина», и `pixels` это
подтверждает числом.

## 2. Вшивка: починить низ, не трогая верх

```bash
python -m image_.image_pair splice deployed.webp fixed.webp --out deployed.webp --pos 1558
```

В `base` строки от `pos` и ниже заменяются строками `patch`; выше `pos` —
ни байта. Кадры строго пара (размер и режим), альфа переезжает как есть,
формат — по расширению `out`: webp с `quality 90 / method 6` (как конвейер),
jpg с `quality`. Проверка сделанной вшивки — тот же `diff-rows` на границе
окна: ниже шва различия ровно чинимые, выше — ноль.

## Грабли

1. **Перегенерация поверх ручных правок** — конвейер не знает, что лица и
   номера в разложенных артефактах правили поверх; сначала `diff-rows`
   (разложенный против свежей генерации), островки над — ручные правки, их
   вшивают обратно `splice`, а не отдают перегенерации.
2. **Bytes ≠ pixels**: webp переписывается с перекодированием — байты верха
   после splice могли сдвинуться, сверяют попиксельно и тоном (`g-b`), не
   хешем.
3. **Пара — строго пара** — размер и режим должны совпадать, RGBA-заплатка
   к RGB-базе не приложится (ошибка, а не «размоет альфу»).
4. **Окно сверки в зоне прозрачности** — у кадров с прозрачным подложием
   различия ниже границы запечённой области молча считают чёрным по чёрному;
   окно `--rect` берут по содержимому, а не по кадру целиком.
