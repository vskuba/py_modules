# uvicorn_sweep — обойти страницы панели и найти мёртвые

Сюита проверяет домен и ручки, но не отвечает на вопрос «а человек это
увидит?». Между зелёной сюитой и работающей страницей лежит слой, где живут
самые неприятные дефекты.

```bash
PYTHONPATH=py_modules python -m uvicorn_.uvicorn_sweep \
    / /admin/orders /admin/data /admin/scenario --skip /node/list
```

```
✓ /
✓ /admin/orders
✗ /admin/data  МОДУЛЬ УПАЛ: ReferenceError: histBox is not defined
✓ /admin/scenario

страниц с находками: 1 из 4
```

Код возврата = число страниц с находками, так что обход годится заставой
перед выкладкой.

## ⚠⚠ Главная находка — упавший модуль, и ловится она только консолью

Ошибка при разборе JS-модуля рвёт его на середине, **но разметка к этому
моменту уже нарисована**: вкладки на месте, панели на месте, текст есть.
Страница выглядит живой и просто не отвечает на нажатия.

Три живых случая, каждый стоил дня:

| Что случилось | Как выглядело человеку |
|---|---|
| обращение к `const` до объявления | «Загрузка…» навсегда |
| опечатка в имени функции | вкладки не переключаются |
| импорт несуществующего | страница рисуется, кнопки мертвы |

⚠⚠ Ловится это **только** уровнем `page-error` в консоли. `window.onerror`
бесполезен: ошибка случается до того, как наш скрипт успел повесить
слушатель. Проверено на себе — нарочно сломанная страница получила «цела»,
пока разбор шёл по `window.onerror` и уровню `error`.

⚠ Уровень именно `page-error`, а не `error`: второй — это битые ресурсы
(«Failed to load resource»), и отбор по нему пропускает ровно то, ради чего
обход затевался.

## Что ещё считается находкой

| Находка | Признак |
|---------|---------|
| `МОДУЛЬ УПАЛ` | `page-error` в консоли |
| `ЗАСТЫЛО на «Загрузка…»` | подпись осталась в видимой панели |
| `ПУСТО` | в панели меньше 20 знаков |
| `не загрузилось` | ресурс ответил 4xx/5xx |
| `не открылась` | браузер не дошёл до страницы |
| `обход не доработал` | скрипт не вернул значение — страница умерла раньше |

⚠ «Долго» находкой не считается намеренно: медленная страница — отдельный
вопрос с отдельными порогами, а в одной ведомости с мёртвыми она даёт шум,
в котором мёртвую не разглядеть.

## ⚠⚠ Вкладки находятся сами

Список вкладок доводом не передают: это вторая копия разметки, и расходится
она молча — на странице завели вкладку, проверка о ней не знает и говорит
«цела». Обходятся все узлы с `data-tab`, какие на странице есть.

## ⚠ Ручки, которых нет намеренно, называет проект

У панели бывают ручки, отсутствие которых законно: `optionalList` в общем
слое глотает их отказ, и страница живёт без них. Такие адреса передаются
`skip` — знать, какие именно, свойство установки, и список в общем слое был
бы знанием проекта не на своём месте.

Фавикон отсеивается всегда: у зеркала его нет по построению, и 404 на него
приходит на каждой целой странице.

## ⚠ Каждая страница — свой заход браузера

Десять страниц — десять заходов, полторы минуты. Один заход с переходами был
бы быстрее, но первая же упавшая страница уносила бы остальные: ошибка
модуля рвёт и навигацию.

## Грабли

1. **Ловить ошибки через `window.onerror`** — упавший модуль не поймается
   никогда, он падает раньше
2. **Отбирать консоль по уровню `error`** — это битые ресурсы, а не
   поломка кода
3. **Список вкладок доводом** — расходится с разметкой молча
4. **Считать 404 фавикона находкой** — обход ругается на каждой целой
   странице и перестаёт что-либо значить
