# Алфавит проекта (text_charset)

> Где у завелись чужие буквы: кириллица — только в комментариях и docstring,
> иероглифов нет нигде. Один проход по дереву вместо ручного скан на каждый
> «добавил файл — проверь язык».

## 1. Что судит и чем отличается от соседей

| Инструмент | Что видит | Чего не видит |
|---|---|---|
| `variable_/variable_cyrillic.py` | кириллицу в **именах** | строки и html |
| `tool_/tool_typo.py --kind cjk` | иероглифы в **прозе** (докстринги, комментарии, md) | строки вне прозы, html целиком |
| `text_/text_charset.py` | **алфавит по ролям файла**: py-строки вне docstring, html целиком, sql-синтаксис, иероглифы где угодно | орфографию, стиль, сами тексты |

Правила по ролям:

- `.py`: строки вне docstring — чистая латиница; комментарии и docstring —
  кириллица норма, иероглиф — находка.
- `.html` — весь файл чист целиком, вплоть до inline-комментария в `<style>`.
- `.sql`: синтаксис (после `sql_split_masked`) — латиница; `COMMENT '...'` и
  комментарии — по-русски можно; иероглиф — везде находка.
- `.md`, `.js`, `.css`, `.json`, `.yml` — иероглифы (след вставки).

## 2. Мера — чужой алфавит, а не «любой байт выше 0x7F»

Em dash, кавычки-лапки, `°`, `×` — типографика: фильтр по любому знаку выше
ASCII выгнал бы их все из каждого английского текста. Судятся блок кириллицы
`U+0400–U+04FF` (весь, с `ё`) и каны/хани/хангыль с CJK-пунктуацией.

## 3. CLI

```bash
python -m text_.text_charset [root]            # находки; выход 1 — есть находки
python -m text_.text_charset --no-strings      # проект с русским текстом как продуктом
python -m text_.text_charset --json            # разбору
```

## Грабли

1. **Строка-класс букв не нарушение** — регулярка, целиком собранная из
   диапазонов, это определение алфавита, а не текст; строки, целиком состоящие
   из чужих букв и дефисов, из суда сняты.
2. **`docs/*.md`, описывающие иероглифы, не нарушают их же** — код в обратных
   кавычках и блоки-заборы из md вырезаются до поиска, как в `tool_typo`.
3. **Кириллица в строках судится не всегда** — в проектах-панелях это
   нарушение, в боте с русским текстом штат; флаг `--no-strings`.
4. **Непарсящийся `.py` — молчание**, не находка: дерево не построить, а
   кричать не на что; файл всё равно не импортируется.
