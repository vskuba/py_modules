# Полосы-локаторы: где в длинном кадре нужный цвет

> Кадр страницы высотой в три экрана ищется глазами вслепую; цветная
> плашка (шапка таблицы, полоса-разделитель) — готовый якорь. Скан ширины
> с шагом находит все строки этого цвета и склеивает их в полосы — кроп
> полосы заменяет десятиминутную возню с crop.

## Как

```python
from image_.image_band import image_band_find, image_band_crop

bands = image_band_find('frame.png', (240, 234, 216), tol=(8, 8, 12))
# [(17093, 17126), (17196, 17324)] — y-диапазоны beige-шапок сверху вниз
res = image_band_crop('frame.png', '/tmp/t8', color=(240, 234, 216), pad=20)
# /tmp/t8_01.png … — по файлу на полосу
```

`ratio` — доля совпавших точек строки (0.75: шум текста внутри плашки не
ломает полосу), `pad` — запас сверху/снизу, чтобы в кроп попала рамка блока.

```bash
PYTHONPATH=. python -m image_.image_band frame.png f0ead8 --tol 8,8,12 --out /tmp/t8
```

## Грабли

1. **Полоса — это цвет, а не смысл**: та же плашка у чужого блока вернёт
   лишнюю пару координат; назначение полосы подтверждают просмотром кропа.
2. **Градиентная плашка скану не ровня** — при `tol` меньше размаха
   градиента полоса рвётся на две; поднимай `tol` либо бери эталон по середине
   плашки.
