# APK на машине: что внутри, не трогая телефон

> Установленный APK — это zip, но содержимое в нём не читается глазами:
> разметка скомпилирована в бинарный AXML, таблица ресурсов — в `resources.arsc`.
> `grep` по APK молчит не потому, что «там нечего искать». `apk_` отвечает на
> вопросы «какой ресурс чем задан» и «что рисует этот вектор» вызовами `aapt2`
> с машины: `apk_entries`, `apk_dump`, `apk_xml`, `apk_pathdata`, `apk_extract`.
> Инструмент — `py_modules/apk_` (модуль `apk_`), CLI: `python -m apk_.apk_`.
> Стянуть APK с устройства — `adb_app_pull_apk` (`mobile_control.md`, § 4).

## 1. Записи архива и таблица ресурсов

`apk_entries(apk, pattern='', base_only=False)` — список записей zip (по
шаблону glob; `base_only` — только без суффиксов конфигураций). Отвечает на
«вообще есть ли этот файл в упаковке».

`apk_dump(apk, grep='', config='default')` — таблица ресурсов (`dump
resources`): возвращает строки, где нашлась подстрока, вместе с ближайшим
заголовком `resource`/`type`/`package` — по одной строке ресурса непонятно, к
чему она относится, а заголовок несёт имя и конфигурацию. Через это ищут, чем
задан экран: `apk_dump(apk, 'AppTheme.Launcher')` отдаёт весь блок темы
запуска, включая `windowSplashScreenAnimatedIcon=@drawable/…` и
`windowSplashScreenBackground=@color/…` — то, что в разметке может и не
существовать (тема из библиотеки).

`config` фильтрует варианты по сегменту `config=`: по умолчанию `default` —
базовые значения без суффиксов; `''` — все варианты (dpi, локаль, ночная
тема). Сравниваешь упаковку Play-маркета с локальной сборкой — смотри и
`xxhdpi`, и `ua`: устройство возьмёт вариант, а не базовую строку.

## 2. Бинарный XML: `apk_xml`

`apk_xml(apk, entry)` превращает скомпилированный layout/drawable в читаемое
дерево (`dump xmltree`). Имя записи — путь в архиве (`res/layout/activity.xml`);
голое имя файла (`activity.xml`) разрешается само, если такое одно: среди
`res/*/<имя>` несколько вариантов — `ValueError` со списком кандидатов (по
одному имени layout и drawable выбрать нельзя, и угадывать незачем).

## 3. Векторы: `apk_pathdata`

`apk_pathdata(apk, entry)` — из xml-иконки только геометрию: список
`{'tag', 'attrs'}` для элементов с `pathData` (имена атрибутов без префикса
`android:`). Так сверяют форму клонированной иконки с оригинальной — числа
против чисел, без растров и глаз: `fillColor` и контуры видны прямо, а
`image_svg_render` (`image_svg.md`) из тех же чисел делает растр для замера.

## 4. Извлечение файлов: `apk_extract`

`apk_extract(apk, entry, out_dir='/tmp/apk_extract', png=False)` — кладёт
файл из архива на диск; `png=True` прогоняет webp через Pillow в RGBA png
(штатный формат иконок Android — webp, смотрибельный не всем). Так достают
сплэш-картинки и растровые слои mipmaps, у которых xml-представления нет.

## CLI

```bash
python -m apk_.apk_ entries /tmp/app/base.apk 'res/drawable*'
python -m apk_.apk_ dump /tmp/app/base.apk windowSplashScreen
python -m apk_.apk_ dump /tmp/app/base.apk AppTheme --config ''
python -m apk_.apk_ xml /tmp/app/base.apk res/layout/activity.xml
python -m apk_.apk_ pathdata /tmp/app/base.apk ic_logo.xml
python -m apk_.apk_ extract /tmp/app/base.apk res/mipmap-mdpi/ic_launcher.webp --png
```

## Грабли

1. **`grep` по APK молчит** — layout'ы лежат бинарным AXML, поиск по тексту
   ничего не найдёт и не скажет, что искал не туда. Содержимое читают
   `xml`/`dump`, текстовые же файлы (например `.json` в assets) видны `entries`
   и извлекаются `extract`.
2. **`aapt2` нет в PATH** — он живёт в SDK, `build-tools/*/aapt2`; модуль ищет
   сам (PATH → `ANDROID_HOME` → `~/Android/Sdk`) и берёт старшую версию,
   сравнивая части номера числами: строковая сортировка ставит `9` старше `10`.
   SDK не установлен — `FileNotFoundError` с внятным текстом.
3. **aapt2 печатает строковый атрибут дважды на одной строке**:
   `A: android:src="@x" (Raw: "x")`. Хвост ` (Raw: ` отсекается; резать
   проверкой «строка начинается с `(Raw:`» бесполезно — продолжение стоит на
   той же строке, и значение уедет с мусором на конце.
4. **Длинные значения (pathData) перелезают на следующую строку** — ключ
   остаётся с незакрытой кавычкой, значение продолжается со второй строки.
   Разбор построчно «ключ=значение» такие значения рвёт; нужен автомат по
   состоянию, как внутри модуля.
5. **Варианты ресурсов — не дубли** — у одного имени по строчке на каждую
   конфигурацию (`xxhdpi`, `night`, `ua`, …). `config='default'` оставляет
   базу; «на устройстве же другое» обычно и значит «устройство взяло свой
   вариант», смотри `--config ''`.
