# geo_osm_dump — адреса целой страны из выгрузки OpenStreetMap

Overpass отвечает на вопрос «что вокруг этой точки» и берёт за это секунды:
замер показал **35–50 с** на запрос у единственного живого зеркала. Пятьдесят
тысяч точек по такой цене — месяц работы. Выгрузка отвечает на другой вопрос —
«все адреса страны разом», — и платится один раз.

| Шаг | Цена (Украина) |
|-----|----------------|
| скачать `europe/ukraine` | 880 МБ, **2 минуты** |
| разобрать | **34 секунды**, 1 234 950 адресов |
| из них годных в заказ | 749 534 (`live` + `point`) |

```python
from geo_.geo_osm_dump import geo_osm_dump_fetch, geo_osm_dump_addresses

path = await geo_osm_dump_fetch('europe/ukraine')
for row in geo_osm_dump_addresses(path, ('live', 'point')):
    ...  # {'street', 'house', 'city', 'postcode', 'lat', 'lon', 'kind'}
```

## ⚠⚠ Вид адреса важнее, чем кажется

В выгрузке три разных вещи с одинаковым `addr:housenumber`:

| `kind` | Что это | Сколько в Украине | Годится в заказ |
|--------|---------|-------------------|-----------------|
| `live` | здание жилого типа | 653 116 | да |
| `point` | адресная точка без здания | 96 418 | да |
| `other` | `building=yes`, магазин, школа | 485 416 | **нет** |

Разделение сделано здесь, потому что по тегам его видно, а по готовой строке
«вул. Шкільна, 7» — уже нет. Смешав виды, однажды пошлёшь посылку в школу.

## ⚠ Улица — тем же правилом, что у Overpass

`geo_osm_address_street`: «Теремська вулиця» → «вул. Теремська». Два источника
обязаны давать одинаковые строки, иначе один и тот же дом ляжет в базу дважды.

## ⚠⚠ Разбор потоковый, память не растёт

`FileProcessor` читает файл потоком, а функция — генератор: страна целиком
никогда не лежит в памяти. Собрать её в список можно, но это миллионы
словарей; лучше писать пачками прямо из обхода.

⚠ `with_locations()` обязателен: без него у контура здания нет координат
узлов, и центр посчитать нечем. Платится это памятью на индекс узлов.

⚠ Центр контура — **среднее по узлам**, а не первый узел: у длинного дома
первый угол отстоит от середины на полсотни метров.

## ⚠⚠ `osmium` требует системного expat

Колесо (1.8 МБ) собрано заранее, но линкуется с `libexpat.so.1`. В
`python:3.11-slim` его нет, и импорт падает — **только в контейнере**, потому
что на машине разработчика expat стоит всегда. В образ ставится `libexpat1`.

## ⚠ Свежесть

Geofabrik обновляет выгрузки ежедневно. `geo_osm_dump_fetch` качает заново,
только если локальный файл старше `fresh_days` (неделя по умолчанию):
перекачивать 880 МБ ради суточной разницы в адресах — чужой трафик.

⚠ Файл пишется во временный и переименовывается в конце: оборванная закачка
иначе оставляет огрызок, который выглядит готовым и разбирается с ошибкой
посреди страны.

## Грабли

1. **Нет `libexpat1` в образе** — `ImportError` при импорте osmium, и только
   в контейнере
2. **`building=yes` принят за жильё** — школы и магазины в адресах заказов
3. **Первый узел вместо центра** — дом «съезжает» на полсотни метров
4. **`list(geo_osm_dump_addresses(...))`** — миллион словарей в памяти
