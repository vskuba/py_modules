# video_ — видео как материал: кадры и лица

Посмотреть видео целиком нельзя, а вопрос «кто тут и на какой секунде» —
обычен. Модуль отвечает на него без модели: ffmpeg нарезает, YuNet ищет лица,
лист показывает всё сразу.

## 1. Как устроено

* `video_frames` — `ffmpeg -vf fps=1/every`: кадр N лежит на секунде
  `(N-1)·every`, это поле `sec`; каталог по умолчанию — `<видео>.frames/`
  рядом с файлом, старые кадры затираются (повторный прогон не должен
  мешать новые со старыми);
* `video_faces` — проход детектором по нарезке (`width=640` — детектору
  хватает, листу хватает, диск не пухнет); кроп — квадрат бокса с полем
  `.55` стороны (лоб и подбородок), центр приподнят на 10% — лицо в кадре
  сидит чуть ниже геометрического центра;
* оценка `score = сторона × дисперсия Лапласа` — большое мыло проигрывает
  среднему в фокусе; дубли поворота (IoU > 0.6 у кадров, разнесённых не
  более чем на 2.5 с) схлопываются в лучший.

Детектор — YuNet из OpenCV (`cv2.FaceDetectorYN`), модель `~/.dsh/models/
yunet2023.onnx` качается с opencv_zoo при первом вызове. Для сверки «чьё это
лицо» это не замена `ai_face` (там insightface-эмбединги) — здесь только
«найти и вырезать», зато без гигабайтных весов.

## 2. API

| Функция | Что делает |
|---------|-----------|
| `video_duration(video)` | секунды через ffprobe (0.0 — ffmpeg не видит файл) |
| `video_frames(video, every_sec, out, width)` | кадры `[{path, sec}]` |
| `video_faces(video, out, every_sec, top, min_side)` | лучшие лица `[{path, sec, score, box, sheet}]` + `faces_sheet.jpg` |

## 3. CLI

```bash
python -m video_.video_ duration video.mp4
python -m video_.video_ frames video.mp4 --every 2 --width 640
python -m video_.video_ faces video.mp4 --top 12 --out faces/
```

## 4. Грабли

* `every_sec` меньше секунды на длинном видео — десятки тысяч кадров гонят
  детектор минутами; для «поймать любое лицо» 2 с — рабочий компромисс,
  для «какое-то лицо крупно» — 5 с;
* кропы с 360p-исходника — апскейл: разглядеть можно, в поиск по лицу
  такое не несут (движки честнее по ≥512 px);
* ffmpeg ищется в PATH; без него `video_frames` возвращает пустой список,
  а не ошибку — пустой ответ листа после «успешного» прогона означает
  обычно именно это.
