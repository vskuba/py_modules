# pdf_report — PDF-отчёт из папки с артефактами: печать, превью, проверки

> Pdf report from images / html report: в каталоге лежат PNG-скриншоты прогона
> и источник (`report.html`, `report.md` или `sections.json`), наружу — PDF,
> постраничные PNG-превью и contact sheet, а между ними две проверки вёрстки,
> которые глазами не меряются: пустые страницы и фигуры выше тела страницы.

## 1. Порядок работы

`pdf_report_build(src, out, landscape=True)` — одна строка: источник собран в
печатный HTML рядом с собой (figure ссылается на `png/…` относительно
источника — печать идёт тем же `file://`), напечатан `pdf_print_html`,
разложен `pdf_render` (превью) и `pdf_contact_sheet` (лист), проверен
`pdf_report_check`. `--forbid` добавляет sweep `data_mask_sweep` по HTML,
тексту PDF и дереву источника. Печать подменяется `print_fn` — тесты живут без
chrome.

## 2. Два грабля, названные числом

- **фигура выше тела**: в A4 landscape с полем 11 mm тело ~132 mm; авторский
  `img {max-height:172mm}` из портретного шаблона не даёт картинке влезть, и
  всё, что шло за ней, уезжает на следующую страницу. Поэтому при печати
  потолок `132 mm` (portrait 160) дописывается **после** авторского CSS, а
  проверка меряет каждый нарисованный Image-XObject по `pdf_xobject_get` —
  прямо по CTM, с поворотом и масштабом.
- **пустая страница**: следствие первого — чернил меньше `--min-ink` (8 % по
  умолчанию) на растере `pdf_render` **и картинок меньше 10 % площади**;
  скриншот живой страницы белый и по чернилам не читается — покрывает ли он
  страницу, считает площадь Image-XObject'ов. Обложку или страницу-разделитель
  можно вывести из счётчика `--skip-page`.

Проверка вызывается и одна, на готовый PDF: `python -m pdf_.pdf_report check
report.pdf`.

## 3. Грабли

- ⚠ Печать живёт в chrome и не терпит молчания: `print_fn` в тестах рисует
  страницы pypdf-потоками — но потоки обязаны уезжать indirect-объектами
  (`writer._add_object`), inline-поток внутри словаря страницы pdfium
  разворачивает белым листом.
- ⚠ HTML источника не правится на месте: enforcement-CSS дописывается в
  копию `-print.html`; авторский файл остаётся как был.
- ⚠ `report.html` приоритетнее `report.md`, тот — `sections.json`; в каталоге
  с обоими берётся первый по списку, молча.
