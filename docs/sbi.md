# sbi_ — поиск по фото без аккаунтов

«Где ещё эта картинка в сети» для анонима: файл залетает на держатель,
каждая ссылка движка открывается браузер-контейнером, выдача читается как
страница.

## 1. Каналы (замерено живьём, 2026-10)

* **catbox** (`sbi_host`) — держатель без ключей и входа; нужен именно URL:
  все анонимные ручки реверс-поиска (`imgurl=`, `rpt=imageview&url=`,
  `uploadbyurl?url=`) принимают картинку **по ссылке**, а загрузку формы
  контейнер исполнить не может (нет JS-eval) — multipart-запрос catbox'у
  заменяет форму;
* **bing** (`iss=sbi&imgurl=`) — по товару и предмету находит годно, по
  лицу даёт общие темы (одежда, фон); ссылки соцсетей в выдаче — ценность,
  остальное — шум агрегаторов;
* **yandex** (`rpt=imageview&url=`) — честнее всех: пустой ответ пишет
  словом («не найдено», `Find an image: пусто`), а не капчей; узнавание
  темы — заголовком `##` («В розыске», APB) — его и показывает `note`;
* **lens** (`uploadbyurl?url=`) — самый сильный по лицам с нормального
  адреса, но с датацентровых выходов и многих резидентных прокси уходит на
  `/sorry` — это `blocked`.

## 2. Статусы — разные ответы, не «всё пусто»

| status | что значит | что делать |
|--------|-----------|------------|
| `ok` | выдача есть (`note` — тема или первый признак) | смотреть `links` и тему |
| `nothing` | движок сказал «пусто» своим словом | направление закрыто |
| `blocked` | капча/`/sorry` на этом адресе | сменить выход (`http_proxy`), не направление |
| `error` | вопрос не задан (держатель молчал, страница мертва) | повторить |

Путать `nothing` и `blocked` — самая дорогая ошибка здесь: первая закрывает
направление, вторая означает «мы ещё не спрашивали».

## 3. API и CLI

| Функция | Что делает |
|---------|-----------|
| `sbi_host(src)` | файл на catbox, ссылка (или '' — держатель молчит) |
| `sbi_search(src, engines, browser)` | `{движок: {status, note, links}}`; `src` — файл или ссылка |

```bash
python -m sbi_.sbi_ face.jpg                       # все три движка
python -m sbi_.sbi_ face.jpg --host-only           # только выложить
python -m sbi_.sbi_ https://files.catbox.moe/x.jpg --engines yandex
```

## 4. Грабли

* facecheck и подобные (файл в JS-дропзону) — не сюда: загрузку файла в дропзону без
  JS-eval контейнер не делает, это направление тут не чинится;
* catbox хранит вечно и без ключа — **не выкладывать то, что не должно
  светиться**; свой хост предпочтительнее, когда он есть;
* Яндекс требует, чтобы картинка открывалась по ссылке напрямую
  (content-type `image/*`, без редиректа на страницу) — catbox это
  выполняет, держатели с «страницей просмотра» — нет;
* выдача бинга и ленса грузится секундами — `wait` признаком `Image`,
  нетерпеливое чтение даёт пустую страницу и ложный `error`.
