# comfy_gen — пачка кадров персоны через ComfyUI-API

> Драйвер исполняет чужую графу: workflow API-JSON с маркерами, гейт по памяти до
> отправки, готовый файл — в проект, на ферме не остаётся ничего лишнего.

## 1. Контракт

* workflow — API-JSON у персоны; маркеры `__PROMPT__` / `__ANCHOR__` / `__SEED__` /
  `__DENOISE__` / `__FACE__` / `__DETAIL__` заполняет драйвер; `_mem` верхним ключом —
  аппетит в ГиБ, обязательный.
* Гейт: память перед отправкой всегда чистится `comfy_gen_free` (свободна всегда,
  цифру ниже держит кэш моделей ComfyUI, а не соседи; нет ручки `/free` — инструмент
  сам перезапускает контейнер и ждёт живого `system_stats`), и лишь потом свободно
  `< _mem + COMFY_GEN_MEM_MARGIN (0.3)` — отказ, не отправляя. Единая
  память GB10: задача, влезшая в память только что, валит всю ферму вместе с чужими
  процессами.
* `--base` всегда явный: адрес фермы знает вызывающий, модуль хостов не знает.
* Ферма — производство, проект — склад: с `--farm-ssh/--farm-container` готовый
  результат (лора train'а, кадры run'а) скачивается в `--out` и стирается на ферме;
  без них глухо остаётся на ферме.

## 2. Размер кадра против памяти — факты прогонов

Аппетит обучения — площадь кадра × число латентов батча, не «модель вообще»
(свободно — после `comfy_gen_free`, при текущей загрузке соседей):

| Задача | Площадь кадра | Свободно на гейте | Исход |
|--------|---------------|-------------------|-------|
| train flux1-dev-fp8, заплатки @ 768×1024 (0.79 МП/кадр, 0.36 ГБ/кадр) | ~24 кадра | 93.5 | `torch.OutOfMemoryError`, не доехал до SaveLoRA |
| train тот же @ 384×384 (0.15 МП/кадр) | те же заплатки | 92–94 | 300 шагов доходит до SaveLoRA |
| run portrait 896×1152 (`_mem: 45`) | один кадр | 47.6 | проходил |

Flux построен на нативном аспекте (2D RoPE): датасет грузится целиком
LoadImageTextDataSetFromFolder в подпапку input с именем персоны, каждый кадр
Vae-энкодится своим, и TrainLoraNode ведёт весь список латентов РАЗНЫХ форм
(multi-res узла; LatentBatch требовал одинаковый размер и калечил пропорции лиц,
пока не доезжал до SaveLoRA). Драйвер лишь доводит габариты до кратно 16
(страйд VAE 8 × патч flux 2) и жался бы пропорционально сверх бюджета площади
`--budget` — внутри бюджета кадр идёт родным размером (лишняя площадь — чужие
ГиБ из чужого соседства).

## 3. Swap: FaceDetailer делает всё грязное, драйвер — только диспетчер

Целое фото уходит в граф узлом `__ANCHOR__`; крой по bbox детектора, маска, денуаз в
латенте, блендинг и обратная вшивка — внутри FaceDetailer (ComfyUI-Impact-Pack +
Impact-Subpack: провайдер `UltralyticsDetectorProvider` живёт в сабпаке, модель
`bbox/face_yolov8m.pt` — в `models/ultralytics/`). Две стадии одной персоны:
`__DENOISE__` (лицо, ~20 шагов) и `__DETAIL__` (текстура, ~10 шагов, геометрию не
меняет); кроп `bbox_crop_factor` 3.0 и `guide_size` 512 — гайд равен размеру обучения
лоры (512²): при плотном 1.5/768 сходство вышло ниже (raw 0.537 против 0.667,
2026-09-14) — согласование с трейном важнее плотного кропа.

Python-диспетчеру остались: якорь (гибридный ранг AI_LOOK_RANK: косинус к лицу
кадра ×0.7 + к центроиду датасета ×0.3, ×ракурс ×цветность — один косинус к кадру
на асимметрии выбрал бы бракованный патч), промпт из замеров (межквартильный тон
25–75% — тень, блик и помада в истинный тон не входят), подгонка цвета выхода
графа (New=(Gen−mean_gen)·std_src/std_gen+mean_src, множитель клипнут [0.8,1.25]),
seed+retry, гейт `score`. Вшивка — скруглённым боксом по всей области, которую
граф перерисовал, без частотной склейки: эллипс по kps меньше перерисованной
области — чужие края за эллипсом ели сходство (0.475 против 0.677 с бокса), а
мелкая текстура кадра сверху генерации — тоже чужое лицо (0.537 против 0.363 при
hf=1, тот же день). Вердикты — в манифест: probe, gen_score (граф до склейки)
и score (после), fit before/after, integrity. Детекция сверки — та же `COMFY_GEN_QA_DET`
(320): сверка идёт тем же детектором, каким платч мерился вручную; на полном кадре
детекция крупнее дет_size роняет score в 0 (замер 2026-09-14: один и тот же кадр —
0.0 при det 1024 против 0.671 при 320).

## 4. Артефакт с фермы: имя не угадать из HTTP

SaveLoRA пишет `{prefix-подпапка}/{stem}_{steps}_steps_{NNNNN}_.safetensors`, где
NNNNN — глобальный счётчик файлов в output-ах, а не seed; у history train-графа
`outputs: {}` (SaveLoRA — не output-нода), из `/view` имя не узнать. Поэтому забор
артефакта — `ls`/`cat`/`rm` внутри контейнера фермы по `prefix` узла SaveLoRA, а не
http. В проект файл уходит под чистым именем `{stem}.safetensors` — счётчик шагов
в имени актива не нужен.

## 5. Перед каждой отправкой — `comfy_gen_free` (он же `comfy_.comfy_gen free`)

1. Выгрузить кэш моделей: `comfy_gen_free()` шлёт `POST /free {unload_models,
   free_memory}`; памяти свободна всегда ~93 ГиБ, цифра ниже бывает только от
   кэша прошлых прогонов. Ждать, пока «само освободится», нечего.
2. Если у этой ComfyUI ручки `/free` нет или она не ответила — тот же инструмент
   перезапускает контейнер (`--farm-ssh/--farm-container`) и ждёт `system_stats`=200.
3. Ручка полезна и сама по себе перед `train`/`run` из чужого окружения: свежий
   лор по тому же пути без выгрузки кэша не перечитается (LoraLoader ключуется путём).

## 5. Приёмка коллекции: манифест — журнал, а спрос — состояние

`comfy_collection_status(каталог персоны)` сшивает `scenes.dataset.json` (что должно)
с `collection/manifest.json` (что нагенерено) и отвечает одной строкой: сколько сцен
закрыто, какие провалены с каким лучшим скором (добивать seed+1000), каких кадров нет
вовсе. Перескоривать ничего не умеет и не должен — вердикт строится на готовых
`score/pass` из строк; сцене без лица (`face_on=false`) скор не нужен, там закрыта
любая строка.

## Грабли

1. **Счётчик в имени лоры ≠ seed** — старый артефакт отличается от свежего только
   имён, молча скачаешь болванку; только ls по stem.
2. **Лор обновлён, а рестарта не было** — LoraLoader отдаёт кэш по пути, генерится
   прежним лицом, манифест этого не видит.
3. **`_mem` без замера** — 768×1024 обучение падало OOM при свободных 93.5: гейт
   из воздуха не собирают, число берут из фактического прогонов (таблица §2).
4. **Промежуточное забыли стереть** — ферма забивается png прежних прогонов; скачанное
   в проект на ферме не живёт.
5. **Манифест прочитали как состояние** — это журнал по строке на кадр: сколько сцен
   закрыто и какие добивать, выводит `comfy_collection_status`, а не ручной разбор строк.
6. **Саппак/детектор не доустановлены** — в v8 FaceDetailer без ComfyUI-Impact-Subpack
   не знает `UltralyticsDetectorProvider`, а без `models/ultralytics/bbox/face_yolov8m.pt`
   провайдер молча пуст — граф swap не стартует вообще.
