# Пачка ссылок в честные файлы: тип по голове, UA браузера, отказ словами

> Скачанная пачка «.jpg» половиной размера оказывается Cloudflare-страницей, и
> `is_file()` у такого огрызка истинен. `web_grab(ссылки, в_каталог)` качает так,
> как отдаёт: тип по магической голове (`file_check`), UA браузерный, страница
> вместо файла — честный отказ, а не молчаливый `.jpg` с `<html>` внутри.
> Инструмент — `py_modules/web_/web_grab.py`, CLI:
> `python -m web_.web_grab URL… --to каталог [--path путь.в.json]`.

## 1. Граница с соседями

`web_peek` отвечает на вопрос «что сервер прислал» (один ответ, глазами),
`web_gallery` вынимает оригиналы из страницы-галереи. Здесь — пачка ссылок
(или JSON-API, где ссылки лежат под точечным путём с `*`) и ни вопроса больше:
скачать, проверить голову, честно доложить о каждом адресе.

## 2. JSON-API разворачивается в ссылки

Под `path` ответ сначала разбирается тем же точечным путём, что и в `web_state`
(`'*'` идёт и по спискам, и по значениям словаря — у MediaWiki ключи `pages`
это id страниц), и уже полученные ссылки качаются тем же порядком.

## Грабли

1. **«цел» у HTML-огрызка с расширением картинки — ложь без этого модуля**:
   `is_file()` истинен, трейнер потом молча учится на `<html>`; здесь обманка
   не доживает до диска — 'почему' называется.
2. **UA — не украшение**: CDN отдают заглушку curl-подобным агентам; дефолт —
   браузерный, своим `ua=` звать только осознанно.
3. **тип определяется головой байтов, а не расширением в URL**: у файла без
   расширения хвост подставляется угаданный, и наоборот — несошедшаяся голова
   видна сразу.
