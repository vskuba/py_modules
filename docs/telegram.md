# telegram_ — подписчики каналов с открытым номером

Канал → список подписчиков → строки `{phone, first_name, last_name, middle_name,
operator_code}` в базу номеров. Bot API списка подписчиков не отдаёт вовсе —
только MTProto (Telethon) под живым аккаунтом, и номер виден лишь тем, кому он
открыт настройками приватности.

## 1. Что отдаёт MTProto (проверено живьём)

* список участников канала доступен только авторизованному пользовательскому
  аккаунту: `iter_participants` отдаёт `User`-объекты, у которых `phone` заполнен
  **только когда подписчик открыл номер**; бот-токен список не видит вообще;
* канал отдаёт не больше ~10 000 последних подписчиков — потолок MTProto;
* `middle_name` не бывает: Telegram не знает отчеств, поле пустое всегда.

## 2. API (всё async)

| Функция | Что делает |
|---------|-----------|
| `telegram_session_start(phone, api_id, api_hash, session, code, code_file, password)` | войти под аккаунтом, вернуть авторизованный клиент; с живой сессией код не нужен |
| `telegram_session_me(client)` | на кого оформлена сессия: id, имя, номер аккаунта |
| `telegram_members_phones(client, channels, limit)` | `{rows, failed}`: строки подписчиков с видимым номером (+380…, оператор отдельно); сорванный канал — в `failed`, не отказ сбора |

## 3. CLI

```
python -m telegram_.telegram_session  --phone … --api-id … --api-hash … --session путь [--code …|--code-file …]
python -m telegram_.telegram_members  @канал… --phone … --api-id … --api-hash … --session путь [--limit N]
```

Код подтверждения приходит в приложение Telegram этого номера; `--code-file` —
чтобы разовый вход не требовал терминала: процесс ждёт файл, хозяин кладёт в
него код, логин продолжается.

## 4. Грабли

1. **Файл `.session` — ключ к аккаунту**: в репозиторий не идёт, утечка файла
   равна утечке аккаунта.
2. Подписчиков «с открытым номером» — малая доля; отсутствие номера у большинства
   не ловится никак: приватность Telegram не отличает «номер скрыт» от «нет».
3. Telethon — тяжёлая зависимость, подключается лениво внутри функций: импорт
   модуля без установленного `telethon` пройдёт, а вызов упадёт.
