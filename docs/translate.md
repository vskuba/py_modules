# Вычитка перевода: орфография, ложные друзья, смысл

Перевод сайта с русского на украинский (wt24-intel, 170 тысяч знаков) прошёл
три круга правки. Каждый ловил своё, и ни один инструмент в одиночку не
справился. Отсюда конвейер из четырёх модулей: три ищут, один сводит.

| Шаг | Модуль | Что ловит | Чего не ловит |
|-----|--------|-----------|---------------|
| 1 | `text_/text_grammar.py check` | слова не из словаря («вопрос», «именно»), согласование («без всякій теми»), чередование у/в, і/й | слово, которое есть в украинском, но значит другое |
| 2 | `translate_/translate_falsefriend.py scan` | ложных друзей и кальки по словарю: «лист» (письмо, а не аркуш), «маєток» (поместье, а не property), «сварка» (ссора), «ні один», «поза панелі» | новое, чего нет в словаре |
| 3 | `translate_/translate_review.py` | смысл: бессмыслица, перевранный род, оборот наоборот — модель, под охраной | надёжно ничего: это кандидаты, список читают |
| 4 | `translate_/translate_fixes.py merge` | сводит правки всех рук | — |
| 5 | `text_/text_grammar.py apply` | применяет только к видимому тексту | — |

```bash
cd py_modules; export PYTHONPATH=.
python3 -m text_.text_grammar check site/index.html --json lt.json
python3 -m translate_.translate_falsefriend scan site/index.html --fixes ff.json
set -a; . ~/.claude/gx10.env; set +a
.venv/bin/python -m translate_.translate_review site/index.html --out rv.json
python3 -m translate_.translate_fixes merge ff.json rv.json agent*.json --file site/index.html --out ok.json
python3 -m text_.text_grammar apply site/index.html --fixes ok.json
```

## ⚠⚠ Грабли, на которых это уже стоило времени

- **Прямой апостроф в литерале JS** («зв'язує» внутри `'…'`) закрыл строку и
  уронил весь скрипт карты — граф перестал бы работать. `apply` теперь
  экранирует замену по месту, `merge` переводит `'` между буквами в `’`.
- **Короткая правка раньше длинной** («Кіев→Київ» до «Кіев, тел.→Київ, тел.»)
  дала 93 промаха из 1642. `merge` сортирует от длинного `from` к короткому.
- **LanguageTool предлагает ближайшее по буквам**, а не по смыслу: «вопрос →
  ворог». Подсказку выбирает читающий.
- **После трёх кругов LanguageTool текст, чистый по его меркам, был полон ложных друзей**
  («Правило листа», «аналітика з одного маєтку», «сварка, садова техніка»,
  «студія названа ім’ям господині» про Михайла). Их увидел только человек при
  вычитке — отсюда `translate_falsefriend`. Найденный глазами тип ошибки
  заносится правилом в `translate_falsefriend_ru_uk.json`, чтобы в следующий
  раз его ловила механика.
- **Цитаты источников** («Звоните», «собираем, ось-ось отправим») — русские
  намеренно. Ни словарь, ни модель цитату от авторского текста не отличают.
- **Проверка после apply обязательна**: скелет разметки (всё, кроме видимого
  текста) сверяется с исходным байт в байт, JS разбирается `node -e "new Function(…)"`.
- **Субагенту — кусок по ~600 строк, не 1500**: куски по 570 находок шли
  больше часа каждый, а фанаут ждал по умолчанию час.
