# GPU — видеопамять: сколько, свободно ли, кем занята

> «Влезет ли модель» и «кто сожрал всю память» — один зонд, но `nvidia-smi`
> отвечает таблицей с единицами измерения, а процессы прячет в отдельный
> запрос `--query-compute-apps`, о котором в момент отладки забывают.
> Обе половины в `gpu_/gpu_vram.py`: числа числами, процессы процессами.

## 1. Платы

```python
from gpu_.gpu_vram import gpu_vram_stat

g = gpu_vram_stat()                    # все платы своей машины
# {'code': 0, 'gpus': [{'index': 0, 'total_mib': 8188, 'used_mib': 3921,
#    'free_mib': 3888, 'util': 0, 'name': 'NVIDIA GeForce RTX 4060...'}], 'error': ''}
g = gpu_vram_stat(0, host='узел-2')    # одна плата, удалённо через ssh_x
```

`gpu=` оставляет плату по номеру; поля — MiB, как их отдаёт драйвер,
пересчёта в байты нет намеренно (у драйвера другая единица, и выдумывать
её — плодить расход).

## 2. Держатели

```python
from gpu_.gpu_vram import gpu_vram_procs

p = gpu_vram_procs()
# {'code': 0, 'procs': [{'pid': 3143934, 'used_mib': 60897,
#    'name': '/path/bin/llama-server'}], 'error': ''}
```

Снимок на текущий миг: между двумя вызовами держатель мог смениться, это
не сторож, а вопрос «сейчас».

```bash
PYTHONPATH=. python -m gpu_.gpu_vram                # JSON по платам
PYTHONPATH=. python -m gpu_.gpu_vram --procs --host узел-2
```

## Грабли

1. **GB10 (единый пул памяти) отдаёт по платам нули**: `total/used/free` —
   не «пусто», а «драйвер не показывает» (`--query-gpu` про единый пул
   молчит). Живые веса держателей — `gpu_vram_procs`, сколько во всём
   пуле — `proc_/proc_mem.py`. Проверено на живой GB10: платы — нули,
   процесс llama — 59 GiB как ни в чём не бывало.
2. **Имя модели может содержать запятые**, поэтому в запросе оно последним
   и разбивается `maxsplit`: жадный `split(',')` порежет «RTX 4090, Lite».
3. **Процессы из контейнера видны с pid их песочницы**: чтобы понять,
   какой это контейнер, pid сверяют с `/proc/<pid>/cgroup` на том же хосте;
   контейнер без собственной pid-пространства показан не будет вовсе.
4. **Нет драйвера — не падение, а `code: -1`** с «nvidia-smi не найден»:
   на машине без GPU зонд отвечает фактом отсутствия, а не трейсбеком.
5. **`free` здесь — «свободно по драйверу»**, а не «можно аллоцировать»:
   фрагментация пула и резервы других контекстов в эту цифру не входят.
