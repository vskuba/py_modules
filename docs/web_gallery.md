# Фото из страницы-галереи: полноразмерные ссылки и закачка без браузера

> Анкеты и каталоги (ladadate и окрестности) отдают в HTML миниатюры с ленивой
> разметкой, а оригинал — тот же файл без суффикса. `web_gallery(url)` выжимает
> из дампа полноразмерные ссылки и знает, какой из них угадан; `web_gallery_download`
> качает с откатом на фактический вариант при 404. Инструмент —
> `py_modules/web_/web_gallery.py`, CLI: `python -m web_.web_gallery URL [--out каталог]`.

## 1. Граница с семейством `web_`

`web_insta` — поларис-дамп Instagram, у него свои кандидаты и свои UA; здесь —
обычный HTML с `data-src`/`srcset` произвольного сайта. Ни браузера, ни стен:
ссылок полно в дампе, Chrome не поднимается вовсе.

## 2. Порядок

Сначала список (`web_gallery`), потом закачка (`web_gallery_download`): тег за
тегом собираются кандидаты всех ленивых атрибутов, сливаются по основанию имени,
вариант без суффикса бьёт угаданный. Имена сохраняются как в дампе — на таких
сайтах это уже хеш содержимого; `gallery.json` дописывается, уже скачанное не
перекачивается.

## Грабли

- **`src` почти везде — миниатюра**: смотреть надо все кандидаты тега, а не
  первый; `srcset` — через запятую с дескрипторами, адрес без дескриптора.
- **суффиксы миниатюр у сайтов разные** (`-s`, `-thumb`, `-200x…`): оригинал
  выводится отжатием и бывает УГАДАН — качать надо с откатом, а не молча 404-ить.
- **служебная графика** (логотип, заглушка lazy-загрузки) в выборку не идёт:
  `.svg`/`.ico` отсекаются на входе.
