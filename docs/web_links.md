# web_links — перепись внешних ссылок: живой факт обязан быть с живой ссылкой

> Разведдок живёт ссылками; ссылки умирают молча — статью снимают, реестр
> переезжает, архив теряет снимок. «Все факты со ссылками» без свежей проверки
> — память, а не проверка. Здесь — честный обход всех `http(s)` в `.md`/`.html`
> пачкой, с повтором там, где host троттлит, и отдельной стопкой того, что
> мёртвым назвать нельзя.

## 1. Как

```python
from web_.web_links import web_links_check

r = web_links_check(['shop_fingerprint.md', 'shop_network_map.html'])
r['checked']                 # уникальных ссылок
r['dead']                    # [{url, status, note, where}] — приговор
r['ask']                     # 401/403/405/429 и 5xx — решить руками
```

Один адрес — одна проверка, где бы ни встречался; `where` — до трёх мест
`файл:строка`.

## 2. Вердикт

| ответ | вердикт | почему |
|-------|---------|--------|
| 2xx/3xx | `ok` | жива |
| 404/410 | `dead` | страницы точно нет |
| коннект/таймаут после 4 заходов | `dead` | хост не отвечает |
| 401/403/405/429 | `ask` | закрывается на скрипт, не «сдохла»; вики, VK — так |
| 5xx | `ask` | сервер есть, но барахлит (crt.sh под нагрузкой) |

Connect-ошибку повторяем до 4 раз с нарастающей паузой: web.archive.org
отвечает и за 2 секунды, и отказом подряд — в параллельном прогоне это
троттлинг, а не смерть снимка.

## 3. Пачкой из-под CLI

```bash
PYTHONPATH=. python -m web_.web_links docs/*.md        # non-ok строки + счёт
PYTHONPATH=. python -m web_.web_links --workers 4 a.md b.html   # щадяще к архиву
```

exit 0 — мёртвых нет; exit 1 — есть `dead` (ставится в заставу доков).

## Грабли

⚠⚠ **UA с контактом, не браузерный**: `research-script/1.0 (contact: …)` —
браузерный UA Википедия и реестра отшивают 403, и проверка выдала бы живые
ссылки мёртвыми.
⚠ «https://www» и обрывки с `…` из прозы — не адреса: хост без точки
отсекается, скобки Википедии (`Ariete_(azienda)`) достраиваются обратно.
⚠ Ссылка за логином не откроется ничем — это стопка `ask`, не баг.
⚠ `--workers` выше 4 для веба архива: архив режет одновременные соединения,
часть снимков встанет мёртвой ложно.
