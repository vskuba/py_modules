# insta_ — профиль Instagram как предмет путешествия

Изучить профиль → решить «интересен ли» → забрать кадры. Без браузера и без
login: всё, что Instagram с 2024 отдаёт анониму-краулеру.

## 1. Что отдаёт анониму (замерено живьём, 2026-09)

* страница **профиля** под crawler-UA — поларис-дамп: карточка (`username`,
  `full_name`, `biography`, `follower_count`, `following_count`, `is_private`,
  `pk`) и медиа постов с подписями — это парсит `web_insta`, карточку — `insta_`;
* списки подписчиков и подписок — **за стеной**: `friendships/<pk>/…?__a=1`
  отвечает 401 `require_login` и под Googlebot, и под app-UA (проверено с чистых
  резидентных IP через прокси) → `insta_followers`/`insta_following` возвращают
  только счётчик, `users: []` и `wall: True` — это не заглушка, а потолок анонима;
* страницы тегов и постов краулеру — login-заглушка без медиа: путешествовать
  нужно списком ссылок на профили, графа ссылок анониму нет.

## 2. API (всё async, `proxy` — опциональный socks5/http адрес из `http_proxy_url`)

| Функция | Что делает |
|---------|-----------|
| `insta_profile(url, proxy)` | карточка профиля из дампа страницы |
| `insta_followers(url)` / `insta_following(url)` | счётчик + `wall: True` (списки — стена) |
| `insta_look(url, proxy, limit)` | осмотр: карточка + медиа (`web_insta_posts`) |
| `insta_pull(url, out, proxy, limit)` | что зацепило — в каталог (`web_insta_download`) |

Медиа не перепарсиваем здесь: второй парсер дампа разёлся бы с `web_insta`
на первой же правке — отсюда импорт, а не копия.

## 3. CLI

```
python -m insta_.insta_ <профиль> [--out каталог] [--limit N] [--proxy socks5://…]
```

Без `--out` — осмотр (карточка, счётчики, первые `limit` медиа), с `--out` —
загрузка. Прокси полезен, когда прямой выход упирается в 429: канал берётся
строкой у `http_proxy_parse` (короткая форма `host:port:user:pass` тоже разбирается).

## 4. Грабли

* обычный UA получает заглушку без медиа — только crawler-UA отдаёт дамп
  (подробности и разбор дампа: `web_insta`);
* запросы к Instagram любят частоту: между походами держать паузы, лимитный
  429 отличается от стеного 401 (`require_login`) — см. §1, путать их нельзя:
  первый лечит пауза или прокси, второй не лечится анонимно ничем;
* поля карточки берутся окном вокруг `follower_count`: вне окна в том же дампе
  стоят те же имена у каждого поста, и `full_name` поста без окна уезжал бы
  вместо имени профиля.
