# socket.io 2 без браузера: чат сайта текстовыми кадрами

> Чат многих сайтов ходит socket.io, и вкладку Chromium держат ради трёх событий.
> Протокол — текстовые кадры по вебсокету, и клиент к нему — полторы сотни строк.
> Модуль — `socketio_/socketio_v2.py`.

## 1. Как звать

```python
from socketio_.socketio_v2 import socketio_v2_open, SocketIoV2Error

async with socketio_v2_open('wss://example.com/chat/socket.io/',
                            query={'token': token, 'type': 'model'},
                            headers={'Origin': 'https://example.com'}) as sock:
    await sock.emit('message', {'type': 'cl_ch_all', 'data': {...}, 'key': key})
    event, args = await sock.next(15)     # ('message', [{...}])
```

Запрос-ответ поверх событий у каждого сайта свой (у одного ответ несёт тот же
`key`, у другого — своё событие), поэтому сопоставление — дело вызывающего:
читай `next` в цикле, пока не придёт нужное.

## 2. Грабли

* ⚠⚠ **Только второе поколение** (`EIO=3`). Признак — `socket.io.2.*.js` в разметке
  страницы. У третьего и четвёртого поколения рукопожатие другое, и **пинг шлёт
  сервер**, а не клиент: этот модуль с ними не работает.
* ⚠ В EIO 3 **пинг шлёт клиент** (`2`), сервер отвечает `3`. `next` шлёт его сам по
  `pingInterval` из рукопожатия — молчащий клиент сервер закрывает через
  `pingInterval + pingTimeout` без слова.
* ⚠ Кадр больше 1 МБ — умолчание `websockets`, — и длинный список сообщений рвёт
  соединение. Предел поднят до 16 МБ (`SOCKETIO_V2_FRAME_MAX`).
* ⚠ Сторож живого HTTP в тестах (`http_mock`) стоит на транспорте httpx и **вебсокет
  не ловит** — в сюите проекта клиент подменяется заглушкой целиком.
* Отказ пространства (`44…`, обычно авторизация) — `SocketIoV2Error`, а не тишина.
