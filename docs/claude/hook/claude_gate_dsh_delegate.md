# Застава разведки — серия чтений без `dsh-board` в режиме `high`

> Работает хуком Claude Code на `Read`/`Grep`/`Glob`/`Bash`, общим для всех проектов.
> Считает, сколько чтений подряд сделано без единой задачи субагенту, и на пятом
> **отменяет вызов**, отдав готовую команду `dsh-board`. Работает **только в режиме
> `high`** (`docs/dsh_board.md`, §7).

## 1. Зачем застава, когда режим объявлен

Режим `high` говорит модели «максимум работы субагентам», и правило это лежит в
контексте каждого хода (`claude_/hook/claude_hook_dsh_mode.py`). И всё равно разведка
уезжает в основную сессию: агент, занятый задачей, читает файл за файлом сам, потому
что **отдать задачу надо помнить**, а в этот момент он занят другим. Напоминание
(`claude_hook_dsh_nudge`) в FREE помогает, но в HIGH это лишь дополнительный контекст,
который можно прочитать мимо и жить дальше. Поэтому в HIGH застава встаёт на пути.

## 2. Отменяет один раз на серию, а не держит

    1…4-е чтение    → пропуск
    5-е чтение      → отмена + готовая команда
    6-е чтение      → пропуск            ← повтор того же вызова проходит
    … ещё пять      → до новой отмены

Застава, отменяющая каждое чтение, — это застава, которую снимут в тот же день: чтение
нужно, чтобы работать. Её задача — не запретить чтение, а не дать разведке **незаметно
стать работой**. Счётчик серии обнуляется отменой, поэтому повтор отменённого вызова
обязательно проходит: агент не зацикливается на отказе.

## 3. Как пройти, не отдавая

Обоснование, а не обход. Строка, начинающаяся с `Сам:`, в ответе агента после
последнего `dsh-board` переносит начало серии на это место — отмены нет, пока с тех пор
снова не набралось `CLAUDE_GATE_DSH_DELEGATE_READS` чтений:

```
Сам: ищу одну строку в одном файле, описать задачу субагенту дороже.
```

«Сам:» ищется на начале **любой строки** текста реплики и терпит markdown-обёртку и
отступы: `**Сам:**`, `- Сам:`, `## Сам:` — то же обоснование, модель оформляет ответ как
хочет. Строка читается из **текста реплики**, а не из выводов инструментов, аргументов
зовов и блоков размышлений, иначе `Сам:` оказалось бы в тексте записываемого файла или в
доводе `grep`, и серия обнулилась бы на чужой строке.

## 4. Что считается чтением

Правило одно на обе заставы — функция `claude_hook_dsh_nudge_is_read`, вторая копия
разошлась бы с первой в первый же месяц:

- `Read`, `Grep`, `Glob` — читают всегда (в DSH имена строчными — их ловит
  `claude_hook_is_tool`);
- `Bash` — чтение, только если **каждый** кусок составной команды (`&&`, `||`, `;`, `|`,
  перевод строки) читает или бездействует. Один `git commit` внутри `… && git log` — это
  работа, а не разведка, сколько бы «читающих» кусков за ним ни шло;
- нейтральные куски серию не портят и чтения не дают: `cd`, `echo`, `true`, присваивания,
  заголовки циклов и `if`/`then`/`fi`, `git fetch`, `>/dev/null` и `2>&1`. Команда целиком
  из нейтральных (`echo one; echo two`) чтением **не** считается — серию двигает чтение,
  а не бездействие;
- действие опознаётся по команде, а не по соседям: `git commit|merge|checkout|push|rebase`,
  `gh pr create|merge|close`, `make`, `composer`, `pytest`, `phpunit`, `docker exec|run|up`,
  `mv|cp|rm|mkdir|chmod|tee`, перенаправление `>` в файл (кроме `/dev/null` и `2>&1`),
  `curl -X POST|-d`, `mysql_query … --write`;
- ведущие `cd <путь>`, `VAR=…`, `do`, `then`, `timeout 10` срезаются: `do git push` — это
  push, а не `do`;
- `mysql_query` и `opensearch_` в любом месте команды — чтение: это запрос в базу и в
  журнал, а не правка; с `--write` — уже правка, не чтение;
- `curl` — чтение, пока в нём нет `-X POST|PUT|DELETE`, `-d`, `--data`: GET разведка,
  POST уже действие;
- `dsh-board` — **не чтение, а делегирование**: он серию и обнуляет.

⚠ Правило смотрит на **все куски**, а не на начало строки и не на «есть ли читающий».
Первая версия была регуляркой по началу строки и молчала на `cd X && Q() { …mysql_query… }; Q`,
на `git fetch -q && ls` и на `cat a.json | jq`; версия «чтение, если хотя бы один кусок
читающий» наоборот ловила правку: `git checkout … && git merge … | grep -i conflict` —
это слияние, а не `grep`.

⚠ Тело heredoc (`<<EOF` … `EOF`) вырезается до разбора: между маркером и терминатором
— текст файла, а не команды. В живой сессии `git commit -F - <<EOF` с `git log --oneline`
в тексте коммита выглядел как чтение именно поэтому.

## 5. Чего застава не делает

- **не работает в `free` и в `off`** — режим выбирает человек, застава ему не перечит;
  в FREE мягкое напоминание, в OFF субагентов не зовут вовсе;
- **не отменяет не-чтения**: правка, сборка, `git commit`, сам `dsh-board` проходят всегда;
- **не заводит бюджет придирок**: у неё нет «прощено на сутки», есть позиция в серии.

## Грабли

1. **Память — позиция в серии, а не придирка, и живёт не в `claude_gate`**: память
   заставы протухает сутки, а протухшая позиция отменила бы вызов заново на том же
   месте. Файл `~/.claude/state/dsh-delegate.json` по `session_id`, как у напоминания.
2. **Путь памяти и режим берутся в момент вызова, а не объявления**: иначе тест бился бы
   о живую память хозяина и о живой `~/.claude/dsh-mode`.
3. **Текущий вызов в журнал ещё не попал** — `PreToolUse` зовётся до него, — поэтому его
   плюсуют к счётчику, а не ищут среди записей.
4. **Смена серии узнаётся по маркеру начала** (`uuid` записи, иначе время, иначе хеш), а
   не по номеру строки: хвост транскрипта сдвигается на каждую запись, и по номеру
   серия «начиналась бы» заново на каждом вызове.
5. **При своей поломке застава пропускает вызов**: сломанный журнал, битая память,
   незнакомая форма записей — молчаливый пропуск, а не отказ (`claude_hook.md`).
6. **Один ответ модели лежит в журнале несколькими записями**: thinking, текст и каждый
   `tool_use` — отдельные строки. Обнуление по «Сам:» видит текстовую строку того же
   ответа, а вызовы с последующих строк считаются уже после засечки; в блоке размышлений
   «Сам:» не обнуляет — там модель говорит с собой, а не обосновывается перед человеком.
7. **Тело heredoc — не команды, а текст файла**: без срезки `git commit -F - <<EOF` с
   `git log --oneline` внутри текста коммита записывался в серию как чтение.

## Чем проверить

```bash
python -m pytest claude_/hook/claude_hook_dsh_nudge_test.py \
                 claude_/hook/gate/claude_gate_dsh_delegate_test.py
```

Транскрипты в тестах синтетические — списки записей той формы, которую разбирают
функции `claude_hook`; живой журнал тестам не нужен.
