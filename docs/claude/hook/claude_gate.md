# Claude Gate — политика прерывания: клапан, бюджет, память

> «Что проверить» у каждой заставы своё, а «придираться ли сейчас вообще» — общее,
> и складывается из трёх вещей: снята ли клапаном, не исчерпан ли бюджет придирок,
> не закрыт ли эпизод. Здесь это написано один раз, а не в каждой заставе.

## 1. Как этим пользуются

    if claude_gate_off(CLAUDE_GATE_TOOL_EXISTS_CHECK_PASS):
        return ''                                          # снята клапаном → молчать

    if claude_gate_asked(ключ, память) >= бюджет:
        return ''                                          # бюджет исчерпан → молчать

    said = <своя проверка>

    if not said:
        claude_gate_forget(ключ, память)                   # придираться не к чему

    else:
        claude_gate_remember(ключ, память)                 # придрались

**Ключ** — то, что застава считает одним эпизодом: у одной путь файла, у другой id
сессии. **Бюджет** застава выбирает сама: раз на файл, две на эпизод.

## 2. Память: запись, а не число

Формат `{эпизод: {поля заставы, 'at': epoch}}`, живёт сутки (`CLAUDE_GATE_SEEN_FOR`).
Отметку времени ставит память, а не застава: забудь она сама — запись не протухнет
никогда, и эпизод останется прощённым навсегда.

Это уже писали дважды, и копии разошлись: одна застава помнила `{путь: epoch}` —
голое число, — из-за чего счётчик придирок не помещался вовсе, а протухшее один
чистил при записи, другой при чтении. Взята запись; часы — параметром (`now=`), без
этого «назавтра придирка вернулась» нечем проверить, кроме как подождать сутки.

## 3. Помнить можно не только счётчик

Под счётчиком лежит общая пара `claude_gate_note` / `claude_gate_noted`, и застава
вправе звать её напрямую: так застава дизайна помнит вердикт «вебовой ли это
проект» — обход дерева на каждом конце хода стоит дороже самой проверки, а состав
проекта за сутки не меняется. Протухание, чистка и проглоченная ошибка записи у обоих
видов памяти общие — в том и смысл.

## Грабли

1. **`claude_gate_forget` зовут, когда проверка ничего не нашла**, а не когда застава
   промолчала по бюджету: иначе исчерпанный бюджет сбрасывал бы сам себя, и застава
   придиралась бы без конца
2. **Наращивание счётчика не должно стирать прочие поля** записи — счётчик придирок и
   вердикт обхода живут под одним ключом (в `remember` это `noted` + слияние)
3. **Имя клапана — своё и длинное**: короткое однажды окажется выставленным в общем
   окружении по чужому делу, и застава замолчит навсегда, а молчащая застава выглядит
   как отсутствующая
4. **Нет файла, битый файл, чужая форма — пустая память, а не исключение**: ошибка
   записи тоже глотается — не суметь запомнить значит придраться лишний раз, а это
   неудобство; упасть — отменить чужую работу без объяснения, а это поломка

## Чем проверить

```bash
python -m pytest tests/test_claude_gate.py    # часы подставляются now= — «назавтра» без суток
```
