# Обучение и генерация на ComfyUI-ферме: монолит-база, патчи трейнера, идемпотентный старт

> Ферма делает, проект хранит. Кадры персоны гоняет `comfy_gen` (workflow в
> API-форме у персоны, маркеры `__PROMPT__`/`__ANCHOR__`/`__SEED__`, вердикт
> score/pass в манифест), базу под трейнер собирает `comfyui_trainer_base`
> (одинокий safetensors → diffusers-каталог), жив ли трейнер на ферме отвечает
> `comfyui_trainer_toolkit_check`, сам трейн гонит `comfyui_trainer_lora`.
> Ферма для всех — параметр вызова (`farm_ssh`/`farm_container`), модули не
> знают ни хостов, ни персон.

## 1. База трейнера: монолит → diffusers-папка

ai-toolkit читает базу папкой (`transformer/ text_encoder/ vae/ tokenizer*/`),
а чекпойнты у ComfyUI — одиночными файлами с comfy-именами ключей (слитый
`qkv`, индексы `block_N` со смещением). Конвертер маппит тела ключей точным
совпадением с `named_parameters()` пустой модели, разметку имён (qkv-сплиты с
явными размерами, `block_N→resnets.N-1`, reshape под conv1×1) знает по картам
в тексте скрипта; разошлось — `SystemExit` с именем ключа, а не молчание.
Конфиги и токенизаторы качаются с ungated-зеркала (gated-репозиторий требует
токен, а конфиги нужны до всякого токена).

## 2. Энкодеры: конфиг модели — всегда явный

transformers 5.5 **проглатывает `subfolder`** в `from_pretrained` и строит
модель из конфига-дефолта: CLIP 512 при 768 у чекпойнта. Признак — трейн
идёт час и даёт generic-лицо без единой ошибки в логе. Лечится патчем
`config=CLIPConfig(**json)` в `stable_diffusion_model.py`; слетает при
пересборке образа тихо — поэтому `comfyui_trainer_toolkit_check` перед
трейном обязателен.

## 3. Трейнер — гость в контейнере

ai-toolkit лежит в контейнере не под git: правки (патч §2, симлинки
`model.safetensors`) — тоже не под git. Старт идемпотентен: живой трейнер не
запускают вторым (две копии по ~35 ГиБ на единой памяти GB10 — OOM всей
ферме), а веса трейнер пишет прямо в `{name}/` — отдельного `weights/` нет.

## 4. Прогон и журналы

Workflow несёт верхним ключом `_mem` — аппетит в ГБ; драйвер не пошлёт
/prompt, если свободно меньше `_mem` + запас. Снимки сходят без EXIF и с
именами-хэшами (sha256[:32]), seed+1000 при минуте провала решает вызывающий.
Логи фермы — с `\r` (tqdm) и вперемешку с бинарным мусором: читать
`errors='replace'`, прогресс — после `tr '\r' '\n'`.

## Чек-лист перед трейном

- [ ] `comfyui_trainer_toolkit_check` → «трейнер цел» (патч 2/2, симлинки 2/2)
- [ ] база собрана `comfyui_trainer_base`, каталог совпадает с `--base` трейна
- [ ] свободная память фермы ≥ `_mem` + запас (единая память — чужой процесс
      влезает в вашу оценку)
- [ ] на ферме уже жив трейнер — не поднимать второго

## Грабли

1. **`subfolder` молча не работает** (§2) — модель из дефолтного конфика,
   трейн даёт не-лицо, в логе тишина; проверять до, а не после ночи.
2. **`weights/` у трейнера нет** — глоб `'**/weights/*.safetensors'` тихо не
   находит ничего; файл лежит в `{name}/` напрямую.
3. **Симлинки `model.safetensors`** в text_encoder/{,2} требует сам загрузчик
   (файл лежит как у diffusers) — без них база не грузится.
4. **Зеркало без токена**: конфиги/токенизаторы берутся с ungated-копии
   того же чекпойнта, иначе 401 на первой же загрузке.
5. **Прогресс с `\r`** — `grep step` по сырому логу видит одну строку;
   сначала `tr '\r' '\n'`.
6. **e4m3 → bf16 каст точен** — конвертер веса не портит; искать «потерю
   качества» в конвертации бессмысленно, дело в энкодерах (§2) или датасете.

## Проверка

```bash
python -m comfyui_trainer.comfyui_trainer_toolkit --toolkit <каталог> --base <база> \
       --farm-ssh <хост> --farm-container <контейнер>        # вердикт «трейнер цел»
python -m comfyui_trainer.comfyui_trainer_base <монолит> <каталог> --farm-ssh … --farm-container …
python -m comfyui_trainer.comfyui_trainer_lora --name … --dataset … --base …  # трейн
python -m comfy_.comfy_gen <workflow.json> …                  # кадр персоны
```
